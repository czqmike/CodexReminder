# Support

Use the [GitHub issue tracker](https://github.com/czqmike/CodexReminder/issues) for bug reports and feature requests.

Before opening an issue:

1. Update VS Code, the official Codex extension, and Codex Reminder.
2. Run `Codex Reminder: Test Taskbar Badge`.
3. Review `Output > Codex Reminder`.
4. Search existing issues.

Include the following non-sensitive information:

- Operating system and version.
- VS Code version.
- Codex extension version.
- Codex Reminder version.
- Whether the workspace is local, SSH, WSL, or a Dev Container.
- Relevant diagnostic lines with usernames, paths, thread IDs, prompts, replies, credentials, and other private data removed.

Do not post Codex session JSONL files, authentication files, full logs, access tokens, or proprietary workspace content.
