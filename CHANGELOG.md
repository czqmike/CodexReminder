# Changelog

All notable changes to Codex Reminder are documented here.

## [1.0.0] - 2026-07-31

- Publish under the permanent extension identifier `czqmike.codex-reminder`.
- Add Marketplace metadata, original PNG icon, anonymized feature illustrations, support documentation, and precise privacy disclosures.
- Require VS Code 1.130 and declare the official Codex extension as a dependency.
- Replace the hand-maintained VSIX manifest with reproducible `@vscode/vsce` packaging.
- Add cross-platform CI, package-content and secret verification, and OIDC-ready release automation.
- Expand coverage for configuration bounds, disabled presentation, malformed and rotated JSONL files, duplicate events, cross-platform paths, and safe PowerShell argument handling.

## [0.1.0] - 2026-07-28

- Initial GitHub release with local Codex event monitoring, status bar unread count, and Windows taskbar overlay.
